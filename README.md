# My Energy Report

Home-Assistant-App, die jede Woche einen PDF-Bericht aus dem **Energie-Dashboard** erstellt
(PV, Hausverbrauch, Netz, Batterie, Wasser), ihn in einer Liste mit Vorschau ablegt und per
**Push** und **E-Mail** verschickt. Oberfläche auf Deutsch und Englisch.

*A Home Assistant app that creates a weekly PDF report from the energy dashboard and sends it
by push notification and e-mail. German and English.*

## Installation

1. **Einstellungen → Apps → App-Store → ⋮ → Repositories**
2. `https://github.com/BreitiDE/ha_my_energy_report` hinzufügen
3. **My Energy Report** installieren und starten, „In der Seitenleiste anzeigen“ einschalten

Details zur Einrichtung stehen in der [Dokumentation](my_energy_report/DOCS.md).
